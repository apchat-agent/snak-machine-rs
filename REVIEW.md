# Current conformance evidence for draft-ietf-snac-simple-12

Task 6 implementation audit, 2026-09-16. This replaces the prototype-only
matrix. The historical independent review remains in git at `842cba8:REVIEW.md`;
its findings were addressed by the first lane and are covered by retained
regression tests. This is implementation evidence for the task 7 review,
not a claim of independent protocol certification or physical interoperability.

The matrix covers all 103 normative rows and ten supplemental commitments
in PLAN2. DONE means implemented with runnable rootless evidence; N/A retains
its exact medium/role condition. The auditor checks all 112 keyword-bearing
draft lines, unique IDs, current code locations and compiled test names, and
rejects missing, partial, ignored or invented evidence. Semantic review remains
necessary; a passing inventory cannot prove a protocol implementation correct.

Run `python3 scripts/conformance_audit.py --matrix REVIEW.md --require-complete`.
The exact executable inventory is `tests/requirements.tsv`. Run
`cargo test --locked --all-features --test conformance --test hostile --test bounded`
for composed scenarios, reproducible mutation seeds and state-capacity soak.
Each cited test also runs in the complete suite. No test uses a physical
interface or privileged port; external sockets are confined to loopback.

Privileged acceptance remains necessary for Linux TAP/AF_PACKET and macOS
utun/pcap/bridge behavior, actual carrier/group operations, filesystem crash
behavior and interoperability with independent DHCP, SRP, DoT, mDNS and NAT64
implementations. Those boundaries and the exact platform functions are logged
in LOG.md under needs privileged acceptance.

The pure Rust rustls provider remains less mature than common native providers;
only the pinned Rust dependency graph and tested TLS paths are claimed. TSR
uses configurable experimental EDNS code 65002 and zero-pads a partial final
Ed448 checksum word (PLAN2 ADDENDUM 5); independent peer agreement is untested.
Local and retiring NAT /96 domains share one resource budget and distinguish
reverse tuples as specified in PLAN2 ADDENDUM 7.
